# Silencia v0.2 — No-Key MVP

Silencia — музыкальный веб-интерфейс на Next.js, который принимает ссылки из разных музыкальных сервисов и умеет искать треки без Spotify Developer API.

## Что изменилось в v0.2

- Spotify Client ID / Client Secret полностью убраны;
- `.env.local` для запуска больше не нужен;
- Spotify-ссылки проигрываются через официальный Spotify Embed;
- SoundCloud-ссылки проигрываются через официальный SoundCloud Widget;
- ссылки Яндекс Музыки распознаются и открываются в официальном сервисе;
- поиск по названию и исполнителю работает через открытый iTunes Search API без ключа;
- найденные треки можно прослушивать как доступные 30-секундные preview-файлы;
- для каждого запроса доступны быстрые переходы в Spotify, SoundCloud, Яндекс Музыку и Apple Music;
- бренд интерфейса переименован из OmniMusic в Silencia.

## Важно про воспроизведение

Silencia не пытается обходить ограничения стриминговых сервисов и не извлекает защищённые аудиопотоки. Полный трек воспроизводится внутри сайта только там, где сам источник разрешает официальный embed. Открытый поисковый каталог возвращает preview URL, поэтому результаты поиска воспроизводятся как короткие превью.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://localhost:3000`.

Никакие API-ключи или аккаунт Spotify Developer не требуются.

## Основные файлы

- `app/page.tsx` — интерфейс Silencia;
- `app/api/search/route.ts` — поиск без ключа;
- `lib/providers.ts` — распознавание ссылок и поисковые ссылки;
- `components/EmbedPlayer.tsx` — Spotify/SoundCloud embed и HTML5 preview player;
- `components/ProviderBadge.tsx` — метки источников.
